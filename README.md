# Rock Paper Scissors 🎮

A simple **Rock Paper Scissors game built using Python**, where the player competes against the computer.

## 📌 About

This project is a beginner-friendly Python game created to practice basic Python concepts such as user input, conditional statements, loops, and the `random` module.

## 🎯 How It Works

The player chooses **Rock, Paper, or Scissors**, while the computer randomly selects its choice.

The winner is decided using the standard rules:

* 🪨 Rock beats Scissors
* 📄 Paper beats Rock
* ✂️ Scissors beats Paper
* 🤝 Same choices result in a Draw

## 🛠️ Technologies Used

* Python
* Random Module

## ▶️ How to Run

Make sure Python is installed on your system.

Run the program using:

```bash
python rock_paper_scissors.py
```

Then follow the instructions displayed in the terminal.
